## ChessPair v1.0.0 — Initial Release

**Free, open-source USCF Swiss tournament pairing software.**

### 🎯 What's New
- Full Swiss pairing engine with backtracking constraint solver
- Multi-section support (Open, U1800, U1600, Scholastic, etc.)
- All USCF tiebreaks: Modified Median, Solkoff, Cumulative, Opposition, Sonneborn-Berger
- Color balancing with triple-color streak prevention
- Automatic bye management
- CSV export for rosters, pairings, and standings
- Fully offline — no account, cloud, or internet required
- MIT Licensed — free forever

### ✅ Installation

**Windows:**
1. Download `ChessPair.exe`
2. Run it (may see SmartScreen warning — click **More info** → **Run anyway**)
3. Start using immediately

**macOS:**
1. Download `ChessPair.dmg`
2. Open DMG, drag to Applications
3. Right-click app → **Open** on first run (to bypass Gatekeeper)

**Linux:**
```bash
git clone https://github.com/Aweswomedude1234/chess-pairing.git
cd chess-pairing
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

### 🔐 Verification

Verify download integrity using SHA-256:

**Windows:**
```powershell
certutil -hashfile ChessPair.exe SHA256
```

**macOS/Linux:**
```bash
shasum -a 256 ChessPair.dmg
```

Compare with checksums above. See [SECURITY.md](https://github.com/Aweswomedude1234/chess-pairing/blob/main/SECURITY.md) for details.
